Part 1: Read a Text File

In a Text File, \n Ends Each Line

The file in an editor:

router 12
desk 9
hall 10

The same file as Python reads it, one string:

'router 12\ndesk 9\nhall 10\n'

file data on the disk with a name. It stays there when the program ends.

text file a file that stores characters. Every editor can open it: .txt, .csv, .py.

\n the newline character. It is one character at the end of each line. An editor does not show it: it starts a new line.

a .jpg, .pdf, or .xlsx file is not a text file. Today: text files only.

This file has 3 lines and 25 characters: 22 that you see, and 3 newline characters.

In main.py:

path the address of a file: the folder names, then the file name

absolute starts at the drive: C:/Users/ayse/EE1021_Project/devices.txt. It works on one computer only.

open, read, close: Read the Whole File

>>> file = open("devices.txt")
>>> text = file.read()
>>> file.close()
>>> text
'router 12\ndesk 9\nhall 10\n'
>>> len(text)
25
>>> print(text)
router 12
desk 9
hall 10

open(path) opens the file for reading. It returns a file object: an object with methods (Lecture 7).

file.read() returns all the characters of the file as one string

file.close() ends the connection to the file. Call it when you finish.

the string is still there after close(). Each \n is one character.

print shows the text as the editor shows it

Three steps for every file: open, read or write, close.

A for Loop Reads a File Line by Line

file = open("devices.txt")
for line in file:
    print(line)
file.close()

Output:

router 12

desk 9

hall 10

in a for loop, the file object gives one line in each turn: 3 lines, 3 turns

each line is a string that ends with \n. In the first turn: 'router 12\n'

print adds one more newline after the \n of the line: the output has empty lines

only one line is in memory at a time: the loop also works for a very large file

Each line still has its \n at the end. The next slide removes it.

strip Removes Spaces and \n from Both Ends

>>> line = "router 12\n"
>>> line.strip()
'router 12'
>>> "   desk 9  \n".strip()
'desk 9'
>>> line
'router 12\n'
>>> line = line.strip()
>>> line
'router 12'

strip() is a string method. It returns a new string without the \n at the end.

it removes whitespace at both ends: spaces, tabs, and newlines. The space inside desk 9 stays.

strip() does not change line. The \n is still there.

to keep the result, assign it to a name

In a loop over a file, the first step is line = line.strip().

split Cuts a String into a List of Strings

>>> "router 12".split()
['router', '12']
>>> "heater,1500,on".split(",")
['heater', '1500', 'on']
>>> name, watts = "router 12".split()
>>> watts
'12'
>>> int(watts) * 2
24

split() cuts the string at the spaces. The result is a list of strings.

split(",") cuts at each comma. The argument is the separator.

two parts and two names: the first part goes to name, the second to watts (Lecture 4)

watts is the string '12'. It is not the number 12.

int(...) or float(...) makes a number from the string

Every value that comes from a file is a string. Convert it before you calculate.

Read a Data File: Loop, strip, split, Convert

total = 0

file = open("devices.txt")
for line in file:
    line = line.strip()
    name, watts = line.split()
    total += int(watts)
file.close()

print("total:", total, "W")

open the file. The loop body runs one time for each line.

remove the \n

cut the line into its two values

convert the string to a number, then add it

close the file after the loop. The program prints total: 31 W.

The values in each turn of the loop:

turn line after strip name watts total
1 'router 12' 'router' '12' 12
2 'desk 9' 'desk' '9' 21
3 'hall 10' 'hall' '10' 31

The pattern for a data file: loop, strip, split, convert.

Part 2: Write a Text File

Mode "w" and write: Put Text into a File

total = 31

file = open("report.txt", "w")
file.write("total power\n")
file.write(str(total) + " W\n")
file.close()
total power
31 W

the second argument is the mode. "w" means write. Python creates the file report.txt: it is empty.

write takes one string. It does not add \n: you write it.

a number is not a string: convert it with str(...), or use an f-string

Python can keep the text in memory until close(). After close(), all the text is in the file.

print writes to the screen. file.write writes to a file, and it takes only strings.

"w" Deletes the Old Text; "a" Adds at the End

mode meaning the file exists the file does not exist
"r" read (the default) read from the start FileNotFoundError
"w" write the old content is deleted Python creates the file
"a" append new text goes at the end Python creates the file 
file = open("log.txt", "a")
file.write("program started\n")
file.close()

"a" each run adds one line. Good for a log of events.

"w" open deletes the old content at once. Good for saving the current data.

program started
program started
program started
program started

with Closes the File Automatically

total = 31

with open("report.txt", "w") as file:
    file.write("total power\n")
    file.write(f"{total} W\n")

print(file.closed)

Output:

True

with open(...) as file: opens the file. The file object gets the name file.

the indented block uses the file

when the block ends, Python calls close(). file.closed is True.

Python also closes the file when an error stops the block

From this slide on, every example uses with. Use it in the project.

Write the Content of log.txt

with open("log.txt", "w") as file:
    file.write("A")
    file.write("B\n")

with open("log.txt", "a") as file:
    file.write("C\n")

with open("log.txt", "w") as file:
    file.write("D\n")

The file log.txt does not exist before the program runs.

  1. What is in the file after line 6?
  2. What is in the file after line 9?

after line 6 two lines: AB and C

after line 9 one line: D

Why: write does not add a newline, so A and B are on one line. Mode "a" adds C at the end. Mode "w" in line 8 deletes everything, then line 9 writes D.

Part 3: Data Files in a Program

A CSV File Stores a Table as Lines of Text

name,watts
router,12
desk lamp,9
heater,1500

The same file in Excel:

name watts
router 12
desk lamp 9
heater 1500

CSV comma-separated values: a text file that holds a table

header the first line has the names of the columns. It is not data.

record every other line is one row of the table: here, one device

the separator is the comma, so a value can have a space inside: desk lamp

CSV is the usual format to move a table from one program to another.

Read a CSV File: Skip the Header, Then Split

total = 0
with open("devices.csv") as file:
    file.readline()
    for line in file:
        name, watts = line.strip().split(",")
        print(f"{name}: {watts} W")
        total += int(watts)

print(f"total: {total} W")

Output:

router: 12 W
desk lamp: 9 W
heater: 1500 W
total: 1521 W

file.readline() reads one line: the header. We do not use it.

the file object remembers its position: the loop starts at the second line

strip() first, then split(",") on its result: two values, two names

watts is a string. int(watts) is the number.

line 9 is outside the with block: the file is closed, and total is still there

The pattern did not change: loop, strip, split, convert. Only the separator is new.

The csv Module Splits Each Line for You

import csv

with open("devices.csv") as file:
    reader = csv.reader(file)
    next(reader)
    for row in reader:
        print(row)

Output:

['router', '12']
['desk lamp', '9']
['heater', '1500']

csv is a module that comes with Python, like math (Lecture 3)

csv.reader(file) makes a reader object from the open file

next(reader) reads one row: the header

each row is a list of strings. You do not call strip or split.

the reader also reads a value with a comma inside quotes: "lamp, desk",9 gives ['lamp, desk', '9']

Excel with Turkish settings writes ; between the values: csv.reader(file, delimiter=";")

A Missing File Raises FileNotFoundError

try:
    with open("devices.csv") as file:
        text = file.read()
except FileNotFoundError:
    print("devices.csv not found")
    text = ""

open for reading stops the program with this error when the file does not exist

two usual reasons: the file is not in the working folder, or the file name has a spelling mistake

put the with block inside try (Lecture 6)

when the file is missing, the except block runs: a clear message, and the program continues with no data

Modes "w" and "a" create a missing file. The folder in the path must exist.

Save a List of Objects: One Line per Object

class Device:
    def __init__(self, name, watts):
        self.name = name
        self.watts = watts

def save_devices(devices, filename):
    with open(filename, "w", encoding="utf-8") as file:
        file.write("name,watts\n")
        for d in devices:
            file.write(f"{d.name},{d.watts}\n")

devices = [Device("router", 12), Device("desk lamp", 9)]
save_devices(devices, "devices.csv")
name,watts
router,12
desk lamp,9

the Device class of Lecture 8 in a short form: it has only the attributes name and watts

a list of two Device objects

a text file stores characters, not objects: we write the attributes of each object

mode "w": after each save, the file holds the current list and nothing old

the header

one line for each object: the attributes in a fixed order, with a comma between them

Load the Objects: One Constructor Call per Line

def load_devices(filename):
    devices = []
    try:
        with open(filename, encoding="utf-8") as file:
            file.readline()
            for line in file:
                name, watts = line.strip().split(",")
                devices.append(Device(name, int(watts)))
    except FileNotFoundError:
        print(filename, "not found: no devices yet")
    return devices


devices = load_devices("devices.csv")
# ... the user adds and changes devices ...
save_devices(devices, "devices.csv")

start with an empty list. Open the file and skip the header.

for each line, the constructor makes a new object from the saved values

no file at the first run: a message appears, and the list stays empty

load one time at the start. save after each change.

Save writes the attributes. Load gives them to the constructor in the same order.

Subclasses: Save the Class Name in a Column

kind = type(d).__name__

kind, name, watts = line.strip().split(",")
if kind == "Lamp":

the list can hold Device objects and Lamp objects (Lamp is a subclass of Device, Lecture 8). The line desk lamp,9 does not say which class.

type(d).__name__ is the name of the class of d as a string: "Device" or "Lamp". It goes in the first column.

load reads the first column and calls the constructor of that class

The line must hold every value that the constructor of its class needs.
